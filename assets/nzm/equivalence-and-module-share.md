## 3.1 等价换算法则（同一量级下做对比）

### 一、问题与目标

不同数值类型（射速 / 武器伤害 / 暴击 / 弱点 / 易伤 / 元素 / 物理）的「投放数量」量纲不同，**策划无法横向比较「+1% 武器伤害 vs +5 RPM 射速 vs +3% 暴击率」谁更有价值**。

目标：**推导出「1 个单位的某类投放 = X 个单位的另一类投放」** 的换算表，让投放和数值包设计有统一标尺。

### 二、推导原理

在「乘性乘区」模型下：
```
DPS = D_base × (1+α_武器) × (1+α_弱点) × (1+α_易伤) × (1+α_物理) × 期望(暴击) × 射速
```

对任一乘区 `(1+α)` 求**对 DPS 的相对偏导**：
```
∂DPS / ∂α = DPS / (1+α)
        ⇒ 相对增量 = 0.01 / (1+α)   （+1% 该乘区，DPS 相对变化率）
```

**这就是等价换算的根公式**：每个乘区对 DPS 的「切线斜率」与其当前值 `(1+α)` 成反比——**乘区当前值越大，再追加同样 % 收益越低**（稀释乘区的本质）。

### 三、代入当前主武器稳态的等价表

**已锁定参数**：
- 武器伤害池 = 1.825（过载膛压 30% + 层积强袭 27.5% + 异态共鸣 25%，理想化）
- 弱点（满层）= 1.49（精密追击 42% + 穿颅者 II 7%）
- 易伤（点金 + 切换）= 1.40（10% + 30%）
- 物理（稳赢之手）= 1.05（5%）
- 暴击基础 = 1.09（爆击倍率 1.30，c=0.30）
- 射速 = 16.67 发/s（1000 RPM）

**等价表（c = 0.30 占位）**：

| 投放类型 | +1% 该乘区 → DPS 相对增量 | 与「+1% 武器伤害」的比值 |
|---|---|---|
| **+1% 武器伤害** | **+0.548%** | **1.00×（基准）** |
| +1% 弱点伤害 | +0.671% | 1.22× |
| +1% 易伤 | +0.714% | 1.30× |
| +1% 暴击伤害 | +0.917% | 1.67× |
| +1% 物理伤害 | +0.952% | 1.74× |
| +1 RPM 射速 | +0.06% | 0.11× |
| +1% 射速（相对）| +1.00% | 1.82× |
| +1% 暴击率 c | +0.30/(1+0.30c) × 100% = +0.275% × (DPS/DPS) | 0.50× |

### 四、关键结论与策划启示

1. **物理伤害 1% 投放效率 ≈ 武器伤害 1% 投放效率的 1.74×**——这是因为物理池几乎没被堆（仅稳赢之手 5%），**值得作为后续投放重点**
2. **暴击伤害 1% 投放效率 ≈ 武器伤害 1% 投放效率的 1.67×**——同理，暴击池只有稳赢之手 8% 基础值，**继续堆暴击伤害是边际收益最高的方向之一**
3. **易伤 1% ≈ 武器伤害 1.30×**——也值得堆，但目前已被点金 30% + 切换 10% 推到 1.40，继续追加会出现稀释
4. **武器伤害池 1% 投放效率最低**（因已被推到 1.825），**继续无脑堆过载膛压/层积强袭边际收益最小**
5. **射速 1 RPM 投放效率最低**（0.11×），**但射速是「双重收益」**——既乘主武器 DPS，又提赛季天赋触发密度（不在本表里）

### 五、c 变化对暴击等价的影响

| 暴击率 c | 暴击基础 = 1+0.30c | +1% 暴击伤害等价 | +1% 暴击率 c 等价 |
|---|---|---|---|
| 0.10 | 1.03 | +0.971% | +0.291% |
| 0.30 | 1.09 | +0.917% | +0.275% |
| 0.50 | 1.15 | +0.870% | +0.261% |
| 0.80 | 1.24 | +0.806% | +0.242% |
| 1.00 | 1.30 | +0.769% | +0.231% |

> 推论：c 越高，**暴击伤害的边际效率越低，暴击率的边际效率也越低**（两条曲线都呈递减）。但 c=0.30 的当前水平，**暴击投放整体仍是高效率方向**。

### 六、限制与扩展

- **本表只算「单点切线斜率」**——当投放幅度较大（如 +10% 武器伤害）时，需要重算新基础 `(1+α+0.10)`，再算下一档
- **未计入条件性来源的覆盖率**（如点金覆盖率 50%，则等效易伤 1.40 实际只有 1.20）
- **未计入稀释乘区的「加和」vs 「乘积」转换**（过载膛压与层积强袭、异态共鸣是加和后再 × 基础，而非各自独立乘）
- **元素伤害 Y 是独立绝对值，不进这张表**

## 3.2 功能模块增益占比（理想化上限）

### 一、模块清单与归类

| 模块 | 主要投放类型 | 投入 DPS 模型的乘区 | 当前已锁定的最高贡献 |
|---|---|---|---|
| **A. 主武器（含武器技能）** | 基础单发伤害 / 基础射速 / 武器技能增伤 | 武器伤害 / 暴击 / 弱点 / 易伤 / 元素 / 物理 / 射速 | 单发 40、射速 16.67、爆击 1.30、火力宣泄 ×3 窗口 |
| **B. 主武器插件** | 武器伤害加幅 / 暴击率 / 弱点 / 换弹 | 武器伤害 / 暴击 / 弱点 | +82.5%（过载膛压 30 + 层积强袭 27.5 + 异态共鸣 25）|
| **C. 副武器** | 对主武器增伤 + 易伤 + 一次性技能爆炸 | 辅助（不自算独立 DPS）| 主动技能（切出→爆炸弹→切回，1s）：爆炸基础 60 吃乘区；爆炸后同时上易伤 +40%（切换易伤 10% + 点金破绽 30%，同池加法）|
| **D. 副武器插件** | 副武器技能充能 / 副武器技能增伤 / 切枪增伤 | 副武器技能 DPS | 技能增幅 +60%；充能弹药 +35% 换弹；切换易伤 +10% |
| **E. 近战** | 物理 / 暴击增伤 | 物理 / 暴击 | 稳赢之手 物理 5% + 暴击 8% |
| **F. 赛季天赋** | 攻击力伤害通道子技能 + 状态 | 独立结算块（ATK=500 固定）| 60/50/65/发；22/26 机械臂 |
| **G. 活动增益卡牌** | 攻/防/血/移速 + 特殊机制 | **本轮先不考虑（用户 09-10 决定搁置）**| 6 种 × 4 等级 × 0-3 张 |

### 二、总增益占比的量化方法

**总 DPS = 主武器稳态 + 爆发窗口 + 赛季天赋 + 副武器 + 近战（被切枪时生效）+ 元素 Y**

每个模块的「增益占比」=「该模块净贡献 / 总 DPS」

**逐模块量化（c=0.30 占位）**：

| 模块 | 公式（理想化最优）| DPS 增量 | 占比 |
|---|---|---|---|
| **A. 主武器（裸装）** | 40 × 1.09 × 16.67 ≈ 727 伤害/秒 | **727** | **27.3%**（主武器贡献基准）|
| **A. 主武器技能** | 火力宣泄 ×3，6s 窗口，100 发 | +47933 伤害/6s = +7989 伤害/秒（平均） | **30.0%（平均后）** |
| **B. 主武器插件** | ×1.825 倍（在 727 基础上）| +600 | **22.5%** |
| **C. 副武器** | 主动技能爆炸 60×3.9944≈239.7×(1+0.30c)/次（代价 1s）+ 爆炸后易伤 +40%（6s 窗口） | 待算（辅助 + 一次性 + 易伤窗口）| — |
| **D. 副武器插件** | 技能增幅 60%、切易伤 10% | +60% 副武器技能 + +10% 易伤 = +8%（主武器基础上）| ~3% |
| **E. 近战** | 物理 5% + 暴击 8% | +13% 主武器 ≈ +95 | **3.6%** |
| **F. 赛季天赋** | 60+50+65 × (1+0.30c) × 2.190 = ~415（按平均触发频次估）| +415（持续）| **15.6%** |
| **G. 活动卡牌** | 本轮先不考虑 | — | — |
| 元素 Y | 独立 | 待算 | — |

> 注：以上**只算模块的主武器基础贡献**，未计入「双重收益」（射速对赛季天赋的放大、点金对易伤的双轨覆盖、弱点覆盖率对精密追击的折算等）。具体百分比会随假设变化，但相对量级稳定。

### 三、增益曲线（增益在时间轴上的分布）

**关键观察**：

1. **主武器贡献（A）**：稳态恒定（每发恒定伤害）→ 增益曲线是**水平线**
2. **主武器技能贡献（A）**：仅 6s 窗口期 ×3 → 增益曲线是**短脉冲**
3. **主武器插件贡献（B）**：常驻叠加（除非换弹清空过载膛压）→ 增益曲线是**水平线（带清空抖动）**
4. **副武器（C+D）**：被动期间（不切枪时）= 0，切枪后短脉冲（含一次性技能爆炸 + 易伤 +40% 6s 窗口）→ **离散脉冲**
5. **赛季天赋（F）**：机械之舞期间持续（12s），结束瞬间叠乘脉冲 → **矩形 + 结束脉冲**
6. **近战（E）**：常驻（携带即生效）→ **水平线**
7. **活动卡牌（G）**：本轮先不考虑（不画曲线）

**理想化上限的关键叠加点**：
- **窗口叠乘 = 主武器爆发窗口 + 机械之舞结束**（6s 内 ×3 主武器 × 死神时刻 50/发 × 完美谢幕 65/发）→ 这是整个周期的「**最高增益峰值**
- 稳态期 = 主武器（A）+ 插件（B）+ 近战（E）+ 赛季天赋并行期（F）→ **持续中位水平**

### 四、模块优先级（理想化最优下的策划投放建议）

按「单位投放带来的 DPS 增量」从高到低：

1. **主武器本身**（基础单发、射速、爆击倍率）— 因为是分母，每提升 1% 直接 × 在所有乘区上
2. **暴击伤害 / 暴击率**（E 稳赢之手 +8%、B 概率坍缩 +6%/未暴击）— 3.1 结论：边际效率最高
3. **物理伤害**（E 稳赢之手 +5%）— 3.1 结论：边际效率次高
4. **易伤覆盖率**（C 点金破绽 +30% × 覆盖率）— 点金 buff 全程覆盖最优
5. **弱点覆盖率**（B 精密追击 +42% × 覆盖率）— 连续命中弱点才能维持
6. **赛季天赋**（F 触发频率）— 依赖射速，本身已并行
7. **武器伤害加幅**（B 过载膛压/层积强袭/异态共鸣）— 已被推到 1.825，边际效率低

### 五、限制

- **副武器只做辅助**（用户 09-10 确认）：不自算独立 DPS，只算「对主武器增伤 + 易伤」+ 一次性技能爆炸（基础 60 吃乘区，代价 1s）；主动技能爆炸后**同时**上易伤 +40%（切换 10% + 点金 30%，同池加法，6s 窗口）
- **活动卡牌（G）整块搁置**（用户 09-10 决定先不考虑）
- **「覆盖率」与「覆盖率×加幅」的关系**——3.1 是按满覆盖算的，真实覆盖率会显著拉低贡献
- **模块之间的「互斥关系」**（如切枪时主武器停止射击）未计

## 六、3.1 + 3.2 整体反思

1. **NZM 当前投放的结构是合理的**：高乘区（物理 5%、暴击伤害 8%、易伤点金 30%）单点效率高，但乘区绝对值都不大——这意味着**继续往这三个方向投放是边际收益最高的**
2. **武器伤害池已经堆得偏高**（1.825），继续无脑堆过载膛压/层积强袭/异态共鸣会进入「投放 1%、DPS +0.5%」的低效率区
3. **赛季天赋和主武器并行的设计**（机械之舞）让射速变成了**双重收益**——这是策划层面的「乘性放大点」，需要在 3.1 等价表里单独标记
4. **「火力宣泄」6s ×3 窗口**是整个流程的**增益峰值**，但只占时长的 6/总周期 ≈ 5-10%——意味着稳态期才是大部分时间的输出形态
5. **活动卡牌（G）本轮先不考虑**——它对「活动期间」与「常规对局」的影响不同，后续需要单独建模再补充

## 六·补、设计视角与体验视角（MT 反馈 2026-09-10 之后补充）

> MT 反馈：「拆解过程过于类似解题过程，要多去想这些数值是为什么要这么配/这么配对玩家的体验如何。」
> 上面的 3.1 / 3.2 全都在回答「数值是多少」。这一节回答「为什么」和「对玩家意味着什么」。

### （一）为什么这么配 —— 设计意图推测

| 数值现象 | 设计意图推测 |
|---|---|
| 武器伤害池 +82.5%（1.825），物理仅 +5%、暴击池小 | 武器伤害是玩家最直觉的成长线，先给足让玩家快速感知变强；物理/暴击池留空是**给后续版本留投放空间**，避免一开始堆满后无成长余地 |
| 火力宣泄「架设攒层 → 机枪消耗 ×3」 | 用「先攒后爆」创造**爆发爽点**；模式切换把无脑连射变成需要排轴的操作，是主动引导玩家学习节奏 |
| 射速双重收益（主武器 DPS + 赛季天赋触发密度）| 提高射速的**性价比权重**，引导玩家在插件/词条上优先堆射速，强化养成方向 |
| 副武器主动技能代价 1s + 上易伤 +40% | 把副武器定位成「**辅助位**」：1s 代价 + 高额易伤窗口，逼迫玩家权衡切枪时机，形成主副配合 |
| 赛季天赋走 ATK=500 通道（不吃武器伤害池）| **系统隔离**：避免主武器变强时赛季天赋被顺带放大，方便两个系统独立调参 |

### （二）对玩家体验意味着什么 —— 体验影响

1. **爽点与节奏（波动型而非平线）**：火力宣泄 ×3 窗口 + 机械之舞结束的「死神时刻 + 完美谢幕」同时触发，是全周期体验高峰。玩家每轮循环都有一次「攒够放招」的爆发感。整个周期是「平稳 → 攒层 → 爆发」的波动型 DPS 曲线。
2. **操作门槛与强度断层（关键风险）**：最优化排轴要同时管理「火力宣泄层数 → 模式切换 → 副武器切枪 → 机械之舞结束对齐」，复杂度不低。**懂排轴与随手玩的玩家，同一套 BD 实战差距会很大**——这是「高上限 vs 高门槛」的取舍。
3. **感知度补偿**：武器伤害池 +82.5% 是「看不见的成长」（只是面板数字变大），而爆发窗口是「看得见的高光」。用爆发的可视爽感补偿平缓成长线的感知不足，是成熟设计手法。
4. **风险点**：模型显示爆发窗口 DPS ≈ 稳态 3 倍，若差距过大，可能出现「只为爆发服务」的极端 build，稳态输出被忽视。需要观察是否两端都有人愿意玩。

### （三）数值投放合理性判断（从设计视角回看 3.1）

- **分层投放思路合理**：先给直觉成长线（武器伤害池），把高边际效率池（物理 1.05、暴击 1.08）留给后续赛季卡牌/插件——这是有意的节奏控制。
- **唯一需警惕**：射速的**双重收益**会同时放大主武器与赛季天赋，投放射速类词条时要算清双重放大，避免强度失控。
- **副武器的 1s 代价设计**：从体验看是「用操作换收益」的正向设计，但需确认玩家能否感知到「切枪上易伤再切回」的收益，否则会变成「高手才用的隐性强度」。
